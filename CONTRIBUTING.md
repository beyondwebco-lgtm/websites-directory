# Contributing to the Beyond Webco Website Directory

This is a documentation-only repository. Do not add website source code, credentials, build output, or client-private assets.

When adding a website:

1. Add a project file in the appropriate `websites/<category>/` folder.
2. Update that category's `README.md`.
3. Update `websites/README.md` when a category changes.
4. Update the root `README.md` master index and totals.
5. Use only confirmed URLs, repositories, categories, and project details.
6. Mark unknown details as `Not documented`; do not infer them.

Use lowercase kebab-case names and keep descriptions concise.
